WHAT'S IN THIS KIT
  carousel-copy.md          → SKILL 1. Plans the slides: count, per-slide text,
                              and a visual direction for each. Copy before design.
  design-taste.md           → SKILL 2. Injects a design system into every image
                              prompt — spacing, hierarchy, 25-word limit, the
                              3-variant + anchor workflow, text-fidelity rules.
  carousel-system-guide.md  → the full written walkthrough (the whole system).

THE SYSTEM IN ONE BREATH
  1. /carousel-copy plans every slide (hook -> value -> CTA, one idea each).
  2. /design-taste turns each slide into an image prompt with taste baked in.
  3. Generate 3 hook variants, iterate until one stops your scroll.
  4. Lock a visual anchor and clone it across every value slide.
  5. Give the CTA the same treatment as the hook.

INSTALL THE SKILLS (pick one)
  A) Claude Code / Cursor: drop each skill into ~/.claude/skills/<name>/
     (carousel-copy.md -> ~/.claude/skills/carousel-copy/SKILL.md, same for
     design-taste). Restart, then use /carousel-copy and /design-taste.
  B) Claude app (Pro/Max): Settings > Customize > Skills > Upload. Zip a folder
     named after each skill with the .md renamed to SKILL.md inside. Turn on code
     execution first (Settings > Capabilities).
  C) No install: paste a skill's contents at the top of a chat with your idea.
     Works as a one-off prompt too.

MAKE IT YOURS
  Both skills are deliberately generic. My specific brand choices (paper texture,
  one orange accent, condensed type) live in clearly marked "edit this" / "customize
  this" blocks — mostly in design-taste's design-system section. Swap in your own
  palette, fonts, and slide furniture; the logic still holds. The rules about
  structure, word budgets, variants, and anchoring are not style choices. They're
  what make the system work regardless of how your slides look.
