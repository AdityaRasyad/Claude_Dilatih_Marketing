# Brief Visual — Meta Ads IT Auditor BNSP · September 2026

**Campaign**: Certified IT Auditor BNSP · 16–17 Sep 2026  
**Platform**: Instagram Feed + Stories + Reels  
**Produksi**: Canva (internal)  
**Deadline produksi**: 8 September 2026  
**Total varian**: 3 creative (A, B, C)

---

## Panduan Warna & Tipografi (Brand Token)

| Elemen | Warna / Spesifikasi |
|---|---|
| Background utama | `#1A1A2E` atau `#0F0F2D` (navy gelap — pakai "Dark Navy" di Canva) |
| Teks utama | Putih `#FFFFFF` |
| Aksen / highlight | Oranye `#FF6B00` atau `#F97316` |
| CTA / urgency | Magenta / hot pink `#E91E8C` atau `#D946EF` |
| Harga coret (old price) | Abu-abu terang `#9CA3AF`, ukuran lebih kecil, efek strikethrough |
| Harga aktif (new price) | Kuning keemasan `#FCD34D` atau putih bold — ukuran 2× lebih besar dari harga coret |
| Badge BNSP | Background magenta/hot pink, teks putih bold |
| Logo dilatih.co | Pakai file logo resmi — "dilatih" navy, ".co" oranye |

**Font Canva yang cocok**: `Plus Jakarta Sans` (Bold untuk heading, Regular untuk body) atau `Inter`. Hindari serif.

## Ukuran File & Export

| Format | Ukuran | Spesifikasi |
|---|---|---|
| Feed static (A, C) | 1080×1080px | PNG atau JPG, max 30MB, rasio 1:1 |
| Carousel slide (B) | 1080×1080px | PNG/JPG per slide |
| Stories (A, C) | 1080×1920px | PNG/JPG, rasio 9:16 |
| Reels thumbnail | 1080×1920px | JPG (cover frame) |

Di Canva: **Download → PNG** (untuk transparansi) atau **JPG quality 100%** (ukuran lebih kecil, cukup untuk ads).
